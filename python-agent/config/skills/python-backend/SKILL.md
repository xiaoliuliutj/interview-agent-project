# Python 后端面试 Skill

按候选人经历安排 Python 基础、Web 框架、异步并发、数据存储和项目深挖。问题必须从简单到复杂，先确认候选人真正使用过的技术，再追问原理、边界和线上故障处理。

- Python 基础覆盖对象模型、迭代器/生成器、装饰器、异常、类型标注、GIL 与进程线程协作。
- Web 服务覆盖 FastAPI、Django 或 Flask 的请求生命周期、依赖注入、校验、鉴权边界和可测试性。
- 异步问题要区分 IO 并发、CPU 密集计算、协程取消、超时和背压，避免只考 API 名称。
- 存储问题覆盖 SQL 事务、索引、连接池、缓存一致性、任务队列和幂等消费。
- 项目追问必须基于候选人简历，不应编造其没有使用过的框架或规模。

当需要核实知识点或给出有依据的题目时，可使用 RAG；检索内容只作为内部依据，不直接输出原始片段。
