# AI Agent 开发面试 Skill

围绕 Agent 架构、规划与执行、RAG、Tools/MCP、记忆、评估和生产可靠性提问。重点区分“调用模型的工作流”和“具有状态、决策和工具边界的 Agent”。

- Agent 架构覆盖 ReAct、计划执行、结构化输出、状态机、多智能体边界和 Harness 思想。
- RAG 覆盖文档解析、切片、Embedding、召回、重排、缓存、引用边界和离线评估。
- Tools/MCP 覆盖工具契约、权限、超时、重试、幂等、参数校验和结果验证。
- 记忆覆盖短期上下文、长期摘要、用户隔离、遗忘/更新策略和一致性。
- 生产化覆盖模型失败、限流、队列、可观测性、成本、提示注入防护与回归评估。

候选人如果只描述框架 API，应继续追问状态归属、失败模式和指标；所有问题和评价都不能泄露内部 RAG 原始片段。
