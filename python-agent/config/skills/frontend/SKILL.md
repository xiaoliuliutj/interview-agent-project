# 前端开发面试 Skill

按 JavaScript/TypeScript、React 或 Vue、浏览器原理、性能和工程化组织问题。先从项目中实际采用的框架和组件切入，再验证基础原理与解决问题的能力。

- JavaScript 重点考察作用域、闭包、原型链、事件循环、Promise、异步错误处理和 TypeScript 类型设计。
- React/Vue 重点考察渲染模型、状态管理、组件通信、生命周期、性能优化和可维护的组件边界。
- 浏览器部分覆盖网络缓存、渲染流水线、重排重绘、事件机制、跨域与安全。
- 工程化部分覆盖构建、代码分割、监控、测试、发布回滚和性能指标。
- 对候选人的项目应追问具体权衡和数据，而非把常见概念当作经验事实。
