# Java 后端面试 Skill

## 面试目标

判断候选人是否能够解释 Java 后端基础、完成常见服务设计，并把方案落到一致性、并发、故障恢复和可观测性上。

## 出题规则

- 优先围绕候选人简历和岗位要求提问；简历中的项目必须追问职责、关键取舍、数据流和故障处理。
- 基础题覆盖 JVM/Java 集合、Spring 事务、数据库索引与事务、Redis、并发和网络基础，但根据候选人经历控制比例。
- 场景题要求候选人先澄清约束，再给出方案、边界和降级策略。
- 算法题只选择能在面试时间内说明思路、复杂度并完成核心实现的问题。
- 评价必须基于候选人的实际回答，区分事实、推断和未回答内容，不因术语数量直接加分。

## 工具使用

需要核对知识点或生成有依据的题目时，使用允许的 RAG 工具；检索结果只作为内部证据，不直接展示原始片段。
