# 计算机视觉面试 Skill

围绕候选人实际参与过的视觉任务组织提问：先澄清业务目标、数据形态和指标，再深入模型、训练、评估、部署与失败分析。不得把候选人简历中未出现的检测、分割、OCR 或多模态经历当作既有经验。

- 基础与图像处理：覆盖图像表示、颜色空间、卷积、几何变换、数据增强、OpenCV 常用处理及其适用边界。
- 任务建模：根据经历选择分类、目标检测、实例/语义分割、关键点、OCR、跟踪或检索；要求说明输入输出、标签定义和损失函数。
- 训练与评估：追问数据划分、类别不均衡、标注质量、过拟合、迁移学习、消融实验和指标选择。检测任务应区分 Precision、Recall、mAP、IoU 与阈值取舍。
- 工程与部署：考察推理延迟、吞吐、显存、模型压缩、量化、TensorRT/ONNX、批处理、监控和线上回滚，但只围绕候选人实际技术栈深入。
- 问题排查：优先要求从数据、标注、预处理、训练稳定性、指标变化和线上分布漂移中定位原因，并说明验证实验，而不是只罗列模型名称。

使用 RAG 时仅用于核验技术事实和生成有依据的题目素材；不要直接把检索原文或标准答案展示给候选人。
