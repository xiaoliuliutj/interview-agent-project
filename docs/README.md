# InterviewGuide 技术文档总索引

本文档严格以仓库当前代码为准，阅读标准参照 docs/创建面试接口_完整函数调用链.md：每个接口或函数都应从入口、参数绑定开始，逐层展开 Service、Repository、实体、消息、外部 HTTP 调用、返回值、失败分支和工程化处理。

## 阅读顺序

1. 第1章先理解启动、服务边界、构建产物和配置装配。
2. 第2章按 Controller 模块阅读 Java HTTP 接口；每个接口独立成文件。
3. 第3章按 Agent、RAG、记忆、Tools、Skills 阅读 Python 下层实现。
4. 第4章对照 SQL 初始化脚本和 ORM 实体阅读表结构。
5. 第5章阅读 Redis 的实际使用位置、键、数据结构和过期策略。
6. 第6章阅读 RabbitMQ 的交换机、队列、路由键、消费确认、重试和死信。
7. 第7章汇总幂等、一致性、可靠性、性能与可改进点。
