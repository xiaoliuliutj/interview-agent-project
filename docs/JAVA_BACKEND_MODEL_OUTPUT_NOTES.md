# Java 上层：模型失败收敛

## 职责

Java 不解析或修复模型 JSON；它只消费下层标准响应、校验请求身份回显、保存任务状态，并把失败原因交给前端。这样模型策略不会泄漏到上层业务代码。

## 简历异步任务

当 Python 返回 `MODEL_OUTPUT_INVALID`（5xx 分类但 `retryable=false`）时，`ResumeAnalysisWorker` 将原因写入 `resume_analyses.error` 并把任务置为 `FAILED`。前端轮询到终态后应展示失败信息，不会无限显示“分析中”。

## 有限重试与超时

- Java 网关的可重试调用最多 2 次。
- RabbitMQ 异步消费者的业务投递最多 2 次。
- 仅网络、超时、限流等下层明确标记为可重试的临时失败可以重试；格式错误、参数错误和一致性错误直接失败。
- Java 到 Python 的读取超时默认 11 分钟，以便在异步消费者中等待下层完成其 120 秒单次调用和有限网络重试，并接收标准失败 JSON；连接超时保持短时间。
